# 세나리 길드 관리

세나리 길드의 공성전·강림원정대·길드전 참여 기록을 관리하는 로컬 웹 앱입니다. 저장소에는 앱 코드와 실행 방법만 올라갑니다. 길드 데이터는 각 복사본의 로컬 D1 파일에 저장되며 Git에는 포함되지 않습니다.

## Windows에서 실행

1. Node.js 22.13 이상을 설치합니다.
2. 저장소를 내려받아 압축을 풀거나 `git clone`으로 복제합니다.
3. `Start Guild Manager.cmd`를 더블클릭합니다.
4. 첫 실행에서 의존성을 로컬에 설치하고 DB 테이블을 준비한 뒤 브라우저를 엽니다.

서버는 `127.0.0.1`에서만 열립니다. 서버를 끄려면 실행 창에서 `Ctrl+C`를 누릅니다. Codex가 코드를 수정하면 실행 중인 앱에 변경 사항이 자동 반영됩니다. `package.json`이나 `package-lock.json`이 바뀌면 실행기를 닫았다가 다시 열어 의존성을 갱신하세요.

## 데이터와 백업

- DB 파일은 `.wrangler/state` 아래에 생성됩니다. `.gitignore`가 이 경로를 Git에서 제외합니다.
- 각 clone은 별도의 길드 DB를 갖습니다. 다른 사람의 데이터는 내려받지 않습니다.
- 이 저장소를 OneDrive 폴더에 두면 해당 PC들의 DB 파일도 OneDrive를 통해 동기화될 수 있습니다. 같은 DB를 여러 PC에서 동시에 열지 말고, 다음 PC에서 실행하기 전에 동기화가 끝났는지 확인하세요.
- **시즌 · 백업** 메뉴에서 JSON 백업을 내려받거나 불러올 수 있습니다.

## 기능

- 2주 단위 콘텐츠 보드와 길드원 명부
- 공성전·강림원정대·길드전 참여 기록
- 시즌 설정과 JSON 백업/복원
- 점수 입력 및 집계는 아직 구현되지 않았습니다.

기본 길드원 이름은 임시값이므로 앱에서 실제 이름으로 바꿔 주세요.
